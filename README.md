# Blood of the Abyss — Showcase

> Toda memória possui um preço.  
> Toda verdade exige um sacrifício.

**Blood of the Abyss** é um jogo de ação 2.5D com horror cósmico, desenvolvido em **Unreal Engine 5.6**, utilizando **C++** e **Blueprints**.

O projeto combina exploração, combate, narrativa ambiental e uma arquitetura modular criada para permitir a evolução contínua dos sistemas de gameplay.

> **Marco jogável atual:** `v0.0.1 — Jardim do Esquecimento`

## Sobre este repositório

Este é o repositório público de apresentação de **Blood of the Abyss**.

O código-fonte completo, os materiais narrativos e os arquivos internos de desenvolvimento permanecem em um repositório privado. Este espaço público será utilizado para apresentar:

- arquitetura e decisões técnicas;
- diagramas dos sistemas de gameplay;
- padrões de desenvolvimento;
- screenshots, vídeos e GIFs;
- registros de evolução do projeto;
- amostras de código que não revelem conteúdo proprietário.

## Visão do projeto

A experiência explora memória, culpa, conhecimento proibido, o Abismo e a Verdade por meio de uma pergunta central:

> Por que o homem teme a Verdade?

Além de seu objetivo criativo, o projeto funciona como um laboratório de Engenharia de Software, com foco em:

- arquitetura modular;
- Programação Orientada a Objetos;
- sistemas de gameplay em C++;
- integração entre C++ e Blueprints;
- versionamento e documentação;
- desenvolvimento incremental;
- construção de níveis 2.5D.
