# blood-of-the-abyss-showcase

> Toda memória possui um preço.  
> Toda verdade exige um sacrifício.

**Blood of the Abyss** é um jogo de ação 2.5D de horror cósmico desenvolvido com Unreal Engine 5 e C++. O projeto combina exploração, combate, narrativa ambiental e uma arquitetura modular voltada à evolução contínua dos sistemas de gameplay.

**Marco jogável atual:** `v0.0.1 — Jardim do Esquecimento`

## Visão do projeto

A experiência explora memória, culpa, conhecimento proibido, Abismo e Verdade por meio da pergunta central:

> Por que o homem teme a Verdade?

Além de seu objetivo criativo, o projeto funciona como laboratório de Engenharia de Software, com foco em:

- Arquitetura modular
- Programação Orientada a Objetos
- Sistemas de gameplay em C++
- Versionamento e documentação
- Desenvolvimento incremental
- Construção de níveis 2.5D

## Tecnologias

- Unreal Engine 5.6
- C++
- Blueprints
- Git e GitHub
- Visual Studio
- Paper2D
